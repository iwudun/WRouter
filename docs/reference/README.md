## 发布状态摘要

当前**源码版本 v0.2.5**（`package.json`），**最新发布安装包 v0.2.3**（2026-11-03）。Windows 侧为 Tauri v2 桌面壳，Linux 侧为纯后端（systemd 用户服务），**两平台**。

| 平台 | 状态 | 备注 |
|---|---|---|
| Windows .exe (NSIS) | **已交付并实测** | `WRouter_0.2.3_x64-setup.exe`(15.43MB,Tauri v2 壳 `desktop/src-tauri/`,后端同进程);自绘标题栏 + 单实例 + 开机自启;安装包实测 26/26 + 服务控制冒烟 19/19;未签名 |
| Linux .rpm | **已产出,容器内冒烟通过** | `wrouter-0.2.3-1.el8.x86_64.rpm`(9.57MB,纯后端:单二进制 + SPA + systemd;依赖仅 `systemd` + `/bin/sh` + `rpmlib`,无 glibc);**systemd 形态「停止服务」真机验证待做** |
| Linux .AppImage | 已下线 | 纯后端无对应形态 |
| macOS .dmg | 配置预留,未验证 | 无构建轨,见 07 |

## 维护规则

1. 本目录描述**当前事实**;与代码冲突时以代码为准,并应尽快修正文档。
2. 行为变更的来龙去脉不在本目录展开,链接到 `../planning/` 对应方案。
3. 新增文档沿用 `NN-标题.md` 序号;过时内容删除而非堆积(历史去 git 找)。
4. **架构重写后要连带核销旧描述**:壳/运行时/打包链路变更时,01/02/04/05/06/07 里同源的陈述要一起改(例如 Electron → Tauri 迁移牵动了进程模型、桥接层方法数、构建工具链、故障排查表)。
